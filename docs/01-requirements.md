# 陰スタグラム（KageSutagram） 要件定義

## 目的
- 「映え」を気にせず、飾らない技大祭の一コマを気楽に投稿できる居場所をつくる。見せ方はネタ（キラキラした写真は許さず、陰に変換してしまう SNS）
- 投稿を会場マップの場所に紐づけ、後から来る人のための現地の情報（混雑・売り切れ・おすすめ・穴場）として残す

## 背景・課題
- 技大祭の写真を上げたいが、キラキラした SNS には気後れする人がいる
- 映える写真を撮らなければ、というプレッシャーで投稿のハードルが上がる
- 反応の数が気になって、投稿そのものを楽しめない
- 「今どこが混んでいるか」「何が売り切れたか」「どこが穴場か」は、その場にいた人しか知らず、後から来る人に伝わらない

## コンセプト
**キラキラは、ぜんぶ陰にする。技大祭期間限定の、映えないSNS。**
- 投稿された写真のキラキラ度を AI が採点し、キラキラしていれば自動で「陰フィルター」をかけてから載せる。キラキラの理由（「ピースが眩しい」など）もネタとして添える
- 反応はハートだけ。投稿した本人には自分のハートの数を見せない（数を気にしなくていい）。周りの人には見えるので、人気の投稿は分かる
- 投稿は会場マップの場所（模擬店・企画・エリア）に紐づき、場所ごとのページとマップから「今そこがどうなっているか」が分かる。混雑・売り切れのような鮮度が大事な情報は、時間がたつと目立たなくなる
- 返信・ハッシュタグ・ニックネームごとの投稿一覧で、SNS としてやりとりできる
- 来場者もログインなし・ニックネームだけで、会場の QR からすぐ使える
- 技大祭の期間＋数日だけ開き、終わったら全部消える

## ユーザーと権限
| ユーザー | 説明 | ログイン |
|---|---|---|
| 投稿者 | 来場者・実行委員。ニックネームで投稿し、自分の投稿を消せる | なし（端末に合言葉を保存） |
| 閲覧者 | タイムラインを見る、ハートを付ける、通報する | なし |
| 運営 | 通報された投稿・返信を確認して非公開にする。開催期間と会場マップの場所を設定する | Slack ログイン（運営に登録済み） |

## 要求
1. ログインなし・ニックネームだけで、写真と一言（40字まで）を投稿できる
2. 投稿前に、AI が写真のキラキラ度（0〜100）と理由を判定する
3. キラキラ度に応じて、自動で陰フィルター（色を落とす・暗くする・粒子・周辺減光）をかけてから載せる。強さはキラキラ度に比例する。元の写真は載せない
4. 写り込んだ人の顔は、全員必ず自動でぼかす
5. 投稿前に AI で不適切な画像・文を弾く
6. 閲覧者はハートを付けられる。ハートの数は投稿者本人には見せず、他の人には見せる
7. 閲覧者は不適切な投稿を通報できる。運営は確認して非公開にできる
8. 投稿者は、端末に保存した合言葉で自分の投稿を消せる
9. 投稿は1端末1日10枚まで
10. 技大祭の期間中と終了後7日まで投稿でき、終了から30日で全投稿を消す
11. 投稿には会場マップの場所（任意）と情報の種類（混雑・待ち時間／売り切れ・状況／おすすめ・感想／穴場・豆知識／ただの日常）を付けられる
12. 会場マップで、場所ごとの最近の投稿と状況（混雑・売り切れ）が分かる。混雑・売り切れの情報は時間がたつと「古い情報」として薄く表示する
13. 場所ごとのページで、その場所の投稿をまとめて見られる
14. 投稿に返信（40字まで、写真なし）できる。返信も AI チェックと通報の対象
15. 一言・返信のハッシュタグで絞り込める
16. ニックネーム（端末）ごとの投稿一覧を見られる
17. 並び替えは、新しい順・人気順（ハート数＋新しさ）・陰度順（元がキラキラだった順）

## 状態の流れ（投稿）
- 判定中 → 公開 → 非公開（運営）／削除（本人）
- 判定で不適切とされたものは「却下」（載せない。理由は大まかにだけ伝える）
- 期間終了から30日で全削除

## 制約・前提
- Web で作る。来場者にアプリのインストールやアカウント登録を求めない
- 写真は判定・加工のため Gemini に送る（投稿画面で周知）
- 未成年の来場者もいる。個人情報（本名・連絡先）は求めない
- 技術は良良タイムズ・隠酒と揃える（Next.js on Cloudflare Workers、D1、R2、Gemini、運営は Slack ログイン）
- 締切：11/24 成果発表

## 決定（11/16）
- 目的：ネタ＋居場所／ユーザー：来場者も／投稿者：ログインなし・ニックネーム
- キラキラした写真：自動で陰に変換して投稿
- 判定：Gemini が採点＋理由／陰フィルター：色を落とす系（キラキラ度が高いほど強く）
- 反応：ハート。本人には数を見せず、周りには見せる
- 荒らし対策：AI で事前チェック、通報＋運営が非公開、顔を自動でぼかす、1端末1日10枚
- 文：一言 40 字＋AI チェック
- 期間：終了後7日で投稿締切、30日で全削除
- 顔：全員必ずぼかす
- 並び順：人気順（ハート数＋新しさ）と陰度順
- 地図：会場マップ上の場所を選ぶ（位置情報は使わない）
- 残す情報：混雑・待ち時間、売り切れ・状況、おすすめ・感想、穴場・豆知識
- SNS 機能：場所ごとのページ、返信、ハッシュタグ、ニックネームごとの投稿一覧
